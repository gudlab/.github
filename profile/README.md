# GudLab

Source-available Business OS: scheduling, forms, support, plus editor tools.

**Start here — GudCal** (the only product whose private SaaS and public core currently move together):

- Cloud: [gudcal.com](https://gudcal.com)
- Public source: [gudlab/gudcal-core](https://github.com/gudlab/gudcal-core)
- Live demo: [gudcal.com/demo/meeting](https://gudcal.com/demo/meeting)
- MCP docs: [gudcal.com/docs/mcp](https://gudcal.com/docs/mcp)

If you want to contribute, open issues on **gudcal-core**, not the private SaaS copy. Star that public repo.
